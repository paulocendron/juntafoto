Falta configurar o servidor

Na Vercel, abra o projeto → Settings → Environment Variables e cadastre:

  • CLOUDINARY_API_KEY e CLOUDINARY_API_SECRET — no Cloudinary, em Settings → API Keys
  • ADMIN_PASSWORD — a senha deste painel (você escolhe)

Depois faça um Redeploy do projeto.
