⚙️ Configuração do JuntaFoto

Siga estes passos para ativar os uploads e a galeria do evento.

1

Criar conta gratuita no Cloudinary

Acesse cloudinary.com/users/register_free e crie uma conta gratuita.

O plano gratuito oferece 25 GB de armazenamento e 25 GB de banda/mês — mais que suficiente para um evento.

2

Anotar o Cloud Name

Após o login, no Dashboard do Cloudinary, você verá o Cloud Name no topo da tela. Anote esse valor — ex.: meuevento123.

3

Criar um Upload Preset sem assinatura

  • No menu lateral clique em Settings → Upload
  • Role até "Upload presets" e clique em "Add upload preset"
  • Configure assim:
Campo Valor
Preset name juntafoto_preset
Signing mode Unsigned
Folder conexao2026
Allowed formats jpg, png, heic, webp

Clique em Save. O nome do preset é o que você vai usar no app.

4

Configurar as credenciais no app.js

Abra o arquivo app/app.js e substitua as linhas no topo:

const CLOUDINARY_CLOUD_NAME = 'SEU_CLOUD_NAME'; const CLOUDINARY_UPLOAD_PRESET = 'SEU_PRESET';

Exemplo com os valores acima:

const CLOUDINARY_CLOUD_NAME = 'meuevento123'; const CLOUDINARY_UPLOAD_PRESET = 'juntafoto_preset';
ℹ️ O Upload Preset Unsigned é seguro para uso público — ele só permite upload para a pasta configurada. Não é uma chave de API secreta.
5

Hospedar o app (3 opções gratuitas)

  • GitHub Pages — suba a pasta app/ num repositório público e ative o Pages nas configurações. URL: seuusuario.github.io/juntafoto
  • Netlify Drop — acesse app.netlify.com/drop e arraste a pasta app/. Em segundos gera uma URL pública.
  • Vercel — npx vercel dentro da pasta app/.
✅ Netlify Drop é o mais rápido — sem conta, sem configuração, 30 segundos para ter o app no ar.
6

Gerar o QR Code para o evento

Com a URL pública em mãos, acesse qr.io ou qrcode-monkey.com e gere um QR Code com as cores do evento:

  • Cor do QR: #004098 (azul)
  • Fundo: #ffffff

Imprima no banner, crachá e telão do evento.

7

Como os participantes acessam

  • Android: abre no Chrome → menu ⋮ → "Adicionar à tela inicial"
  • iOS (iPhone): abre no Safari → ícone de compartilhar 📤 → "Adicionar à Tela de Início"
  • Funciona também diretamente no browser, sem instalar nada
